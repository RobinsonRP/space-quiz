# Space Explorer Quiz

A standalone, single-file space trivia quiz with 10 questions, score tracking, animated feedback, and light and dark themes.

Open `Space-Explorer-Quiz.html` in a browser to play. No server, dependencies, or build tools are required.

## Tests

The focused personal-best tests use Node.js 18 or later's built-in test runner:

```sh
node --test tests/personal-best.test.cjs
```
